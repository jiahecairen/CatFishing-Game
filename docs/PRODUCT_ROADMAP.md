# 产品路线图 — v0.1 后的长期规划（**严禁自动前移**）

## 范围拆分

| 阶段 | 必须完成的焦点 | 明确边界 |
|---|---|---|
| v0.1 | Godot 透明桌面技术原型、临时猫船、自动捕鱼、三种鱼、鱼篓/金币/本地存档、测试 | 无正式角色创建/船舱/世界/联机/付费 |
| v0.2 | 首次启动完整自建猫、微型外观船舱、猫咪自主生活、室内活动概念与桌面思想气泡、AFK/退出收益差别 | 不强制完整森林湖泊世界 |
| v0.3 | 森林湖泊可游玩世界、互动新手序章、手动捕鱼、NPC 售鱼、进阶升级与生活玩法 | 仍以单人体验为主 |
| v0.4 | 桌面模式和完整游戏的权威状态安全切换，跨模式进度与交易边界验证 | 不代表所有联网系统完成 |
| 后续版本 | 丰富地图、任务、钓具、家具、开放多人基础/Steam 集成与付费门禁 | 单人完整内容免费；多人在线功能一次性付费 |

## 已确定的长期硬性产品规则（不能在未来设计时遗失）

### 猫咪 / 船舱 / 桌面表现

- 初次启动玩家**必须自己创建猫咪**，不是预置 Moon；一旦确认，猫咪固定姓名与基础外观不可重新选择，换装/配饰可改。玩家昵称单独可改。所有模式和未来联机共用同一只自己的猫。
- 有初见森林湖泊可跳过/重播新手剧情：遇 NPC、移动、拿竿、第一次手动钓鱼、获得船；启动动画依据白天/天气/心情简化。
- 小船自带**外观看起来很小、内部可扩展**的生活舱。桌面上只显示小船外壳+猫，不展示完整室内；猫入舱可显示简短、可悬停重看的**漫画思想气泡**表达真实生活活动。
- 猫在甲板捕鱼与船舱休息、阅读、做饭间**自主选择**，用户**不能配置行为时间表/优先级/强制专注捕鱼**；在舱时实际不捕鱼，收益下降。结束当前捕鱼事件后才可入舱，不中途丢失未结算事件。
- 稀有趣味动画自然低概率发生，不设收藏、图鉴、历史、回放/强制触发。
- 船只升级/外观/家具以后逐步实现：个人一艘船、造船厂做大型升级、金钱加离线可得材料、船体多预设主题、室内家具布局保存多套配置，允许免费装饰和可选纯外观 DLC；不卖单人地图或数值优势。

### 桌面与交互

- 按屏幕保存不同显示器位置/大小；拖动、单击、双击进入完整游戏、右键菜单；猫进舱单击船显示状态菜单、双击依然进完整游戏；避免遮挡全屏应用和专注工作。
- **SDD-175** 覆盖旧 **SDD-076**：桌面可见窗口固定 30 FPS，不再采用旧的分档可见 FPS 策略；隐藏时减少渲染但不能触发“完全退出”收入。
- 声音及思想气泡低打扰，勿扰/全屏/隐藏时减少提醒；不采集用户屏幕内容或键盘数据。

### 钓鱼、退出收益及联网

- 捕鱼状态机 `CASTING → WAITING → HOOKED → REELING → SETTLEMENT`；钓鱼有效时间/事件/结算不依赖画面帧数。
- 自动捕鱼随机等待初值 20–60 秒，固定 seed/虚拟时间测试可复现；未来可叠加钓具、鱼种、天气影响。
- 完全退出后允许有限、弱于运行时的离线收益：初始约 8 小时上限，可升级约 24 小时；不产出传奇/特殊事件；**此功能不在 v0.1**。
- 完整单人游戏（地图、角色、鱼种、日常进度、NPC、烹饪、水族馆等）免费；仅**在线多人**一次性付费，可另提供纯外观 DLC；没有免费版单人内容付费墙。
- 多人初期最多 4 人，架构为未来 8+ 预留升级，Steam 网络适配，房主权威、每人持有自己鱼/财产；不允许玩家赠鱼、送金币、物品交易；不开自由文字聊天，仅表情/预设短语。
- 曾设允许已付费房主邀请未付费朋友以**受限协助身份**加入，不代表免费朋友获得完整付费联机权益；具体权限以后再实施和验收。

### 持久化、开发流程

- 单一权威存档、本地备份/导出与可恢复日志；未来 Steam Cloud 冲突须用户自己选择，不能只按时间戳替换；不搭建自有云账号。
- Agent 开发以标准工单、Git 变更、独立审查和 CI 证据驱动；重大变更需用户审批，提案池与已冻结 MVP 分离。
- 用户现确定主开发执行器是 **DeepSeek Harness Desktop**、优先本地 Qwen Flash 单模型，并非 Codex；后续即便多 Agent，也必须在本地资源可支持后再设计调度。

## 路线图不是未来版本的完整 SDD

当前未审计全部早期原始访谈，不能将本文件充当 v0.2+ 逐字段冻结规格；进入后续阶段时需要重新审查相关已确认决策、未定字段和正式接口。**不得把长期规划作为 v0.1 开发的借口。**
